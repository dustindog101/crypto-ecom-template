# Schema-Driven Product Customization Model

We decided to support a hybrid catalog model: standard physical and digital products alongside declarative JSON custom field schemas (text inputs, selects, secure asset upload slots). Instead of hardcoding product-specific attributes (like ID pirate forms), products declare their required inputs dynamically in the catalog, enabling any business domain (merchandise, software, private services, custom fabrication) to run on the template without modifying core checkout code.
