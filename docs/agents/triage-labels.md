# Triage Labels

The five canonical triage roles:

- `needs-triage`: Newly arrived issue awaiting categorization.
- `needs-info`: Blocked on information or feedback.
- `ready-for-agent`: Unblocked, fully specified, and ready for autonomous agent implementation.
- `ready-for-human`: Requires manual human action or decision.
- `wontfix`: Ruled out of scope.
