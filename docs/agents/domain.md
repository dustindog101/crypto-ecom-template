# Domain Docs

This repository uses a **single-context** domain layout.

## Location

- Domain Glossary: `CONTEXT.md` at the root.
- Architectural Decision Records: `docs/adr/` numbered sequentially (`0001-slug.md`, `0002-slug.md`, etc.).

## Rules

- Consult `CONTEXT.md` for canonical terms before creating new modules or components.
- Use `_Avoid_` alternatives strictly.
- Record hard-to-reverse architectural decisions in `docs/adr/`.
